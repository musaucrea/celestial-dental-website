# Deployment policy

- Deploy website and API changes to staging/preview only by default.
- Never deploy, promote, sync, or copy changes to the production site or production cPanel files unless the user explicitly approves that specific production release.
- A general request to "deploy", "publish", "fix the website", or "make it live" does not override this rule; ask for explicit production approval.
- Verify changes on the staging URL and provide that URL to the user for review.
